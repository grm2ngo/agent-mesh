# example/ — one completed wave of a trivial host project

This is a finished example wave of a trivial host project (a greeting
module). Files are pre-filled with realistic content — nothing here is
generated at runtime.

Read in this order (5 minutes):
1. `AGENTS.md` — the host project's law (templates/AGENTS.md, filled in).
2. `STATE.md` — end-of-wave state: no agents running, one queued item.
3. `AGENT_FRICTION.md` — two blockers, each with a dispatcher triage line.
4. `AGENT_VERDICTS.md` — three rows + one VERIFIED LEDGER entry.
5. `VARIABLES.md` — wave economics + the SOLVED / OPEN board.
6. `SENTINEL.md` — one clean sentinel cycle.
7. `src/` — the artifact itself: `node --test` passes.

Everything here is generic and fictional. Pattern-match the shapes, not
the content.
